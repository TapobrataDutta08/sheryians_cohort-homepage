# Sheryians Cohort Homepage

A fully responsive frontend landing page built using pure HTML and modern CSS (utilizing Flexbox). It features a clean, fluid layout designed to showcase course modules and student cohorts seamlessly across all screen sizes without any external frameworks.


## Features

* **Pure HTML & CSS:** Built entirely with semantic HTML5 and vanilla CSS3 without heavy frameworks.
* **Flexbox Layout:** Fluid alignment and distribution for all screen viewports.
* **Custom Typography:** Integrated custom font files (`Manrope` and `NeueMachina`) for unique branding.
* **Asset Integration:** Includes custom background graphics and structured sections tailored after Sheryians Coding School aesthetics.

## Getting Started

1. Clone the repository or download the source files.
2. Open `index.html` in your web browser or live server to view the homepage.
